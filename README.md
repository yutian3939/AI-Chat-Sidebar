# AI Chat Sidebar - Edge 浏览器扩展

MD3 风格 AI 对话侧边栏，支持 OpenAI 兼容 API。支持图片理解、文件上下文、框选截图，特别优化超星学习通作业自动答题。

## ✨ 功能特性

### 通用 AI 对话
- 🎯 **右侧悬浮球** — 可拖拽定位，点击展开/收起侧边栏（32px）
- ↔️ **拖拽调宽** — 左边缘拖拽调整侧边栏宽度（300px ~ 70%），持久化记忆
- 💬 **流式对话** — 支持 SSE 流式响应，逐 token 实时渲染
- 🎨 **MD3 主题** — Material Design 3，6 套配色 × 亮色/暗色/跟随系统
- 📝 **Markdown 渲染** — 标题、列表、代码块（一键复制）、链接、KaTeX 数学公式
- 🕐 **对话历史** — 自动保存 + 历史面板查看/切换/删除，附件标签保留
- ✏ **新建对话** — 一键开启新会话，旧会话自动存入历史
- 🔗 **多供应商管理** — 预设 OpenAI / DeepSeek / 通义千问 / GLM / Moonshot，支持自定义

### 🖼️ 图片理解 & 文件上下文
- 📎 **附件上传** — `+` 按钮、拖拽文件到侧边栏、Ctrl+V 粘贴图片，支持图片（缩略图）和文本文件
- ✂️ **框选截图** — 截图按钮进入框选模式，8 个手柄自由调整区域位置大小，点 ✓ 确认
- ⚡ **快速截图** — 开启后松手直接截图发送，跳过调整步骤
- 👁️ **多模态识别** — 选「使用主模型」，图片直接发给多模态模型识别
- 📝 **视觉模型转述** — 先调视觉模型描述图片，再将文字描述交给纯文本主模型
- 📄 **文件注入** — 文本文件内容透明注入 AI 上下文，气泡仅显示文件名标签

### 🎓 超星学习通自动答题
- 📋 **自动识别** — 检测页面单选题，显示「▶ 自动答题」按钮
- 🤖 **逐题作答** — 提取题目 → 调用 AI → 自动点击选项
- ⏯ **暂停/恢复** — 点击暂停，再次点击继续；长按结束
- 📊 **进度显示** — 按钮自身充当进度条，实时显示 `5/18`
- 📦 **结果面板** — 折叠式答题结果，显示题号+答案+解析
- 💬 **上下文追问** — 每道题的问答存入对话上下文，可继续追问
- 💾 **防丢保护** — 自动点击页面「暂时保存」，暂停/结束/每 3 题触发
- ⏭️ **跳过已答** — 设置中可选择是否跳过已答题目

### 兼容性
- 🔌 OpenAI / DeepSeek / 通义千问 / GLM / Moonshot 等服务商
- ⚙️ 自定义 API 端点（自动补全路径）、Key、模型、系统提示词

## 🚀 安装

1. 打开 Edge，访问 `edge://extensions/`
2. 开启右上角 **"开发人员模式"**
3. 点击 **"加载解压缩的扩展"** → 选择项目文件夹

> 修改代码后需在 `edge://extensions/` 点击扩展卡片的 🔄 刷新，**再刷新目标页面**。

## 📖 使用说明

### 首次配置

1. 点击右侧悬浮球 → 展开侧边栏
2. 头部 ⚙️ → 设置页：
   - **供应商**：选择或自定义，填写 Base URL / API Key，管理模型
   - **主模型**：选择模型 + 测试连接 + 系统提示词
   - **视觉模型**：选择「无 / 使用主模型(多模态) / 使用视觉模型转述」
   - **答题设置**：跳过已答题目开关、快速截图开关
   - **主题**：模式（系统/亮/暗）+ 6 种配色

### 日常聊天

| 操作 | 方式 |
|------|------|
| 发送消息 | `Enter` 或点击发送按钮 |
| 换行 | `Shift + Enter` |
| 添加图片/文件 | 输入框上方 `+` 按钮 / 拖拽到侧边栏 / Ctrl+V |
| 框选截图 | 输入框上方 ✂️ 按钮 → 拖拽选区 → 调手柄 → 点 ✓ |
| 快速截图 | 开启开关 → 框选松手直接发送 |
| 移除附件 | 点击附件标签上的 ✕ |
| 新建对话 | 头部 ✏ 按钮 |
| 查看历史 | 头部 🕐 按钮 |
| 拖拽悬浮球 | 按住上下拖动 |
| 调整侧边栏宽 | 左侧边缘拖拽 |
| 关闭侧边栏 | ✕ 或点击悬浮球 |

### 图片理解

| 方案 | 说明 |
|------|------|
| **使用主模型** | 图片以 image_url 多模态格式直发（需 gpt-4o / qwen-plus 等视觉模型） |
| **使用视觉模型转述** | 先调视觉模型获取文字描述，再将描述交给纯文本主模型 |

### 自动答题（学习通作业页面）

1. 打开作业页 → 展开侧边栏 → 输入框上方出现「▶ 自动答题」
2. 点击 → 开始逐题作答，按钮显示进度
3. **点击** → 暂停（自动保存），再点击 → 恢复
4. **长按 800ms** → 结束答题（自动保存）
5. 结果面板出现在消息列表中，可折叠/展开
6. 答完后可在聊天框追问（如「第 3 题为什么选 C？」）

### 常用 API 端点

| 服务商 | API 端点 |
|--------|---------|
| OpenAI | `https://api.openai.com/v1/chat/completions` |
| DeepSeek | `https://api.deepseek.com/v1/chat/completions` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` |
| Moonshot | `https://api.moonshot.cn/v1/chat/completions` |
| GLM | `https://open.bigmodel.cn/api/paas/v4/chat/completions` |

## 🔒 隐私说明

- API Key 存储于 `chrome.storage.sync`，对话历史存储于 `chrome.storage.local`
- 图片 dataUrl 通过 `chrome.storage.local` 临时中转，用后即删
- 请求直连服务商，不经过第三方
- 对话历史在浏览器本地持久化，可随时管理/删除
