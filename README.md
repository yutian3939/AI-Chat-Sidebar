# AI Chat Sidebar - Edge 浏览器扩展

MD3 风格 AI 对话侧边栏，支持 OpenAI 兼容 API。**内置 Agent 模式**，AI 可自动操控浏览器——打开网页、点击、输入、搜索、执行 JavaScript，**跨标签页实时同步**。同时支持图片理解、框选截图，以及超星学习通自动答题。

## ✨ 功能特性

### 🤖 Agent 模式（浏览器自动化）
- 🔓 **自主操作** — AI 可打开标签页、点击元素、输入文本、滚动页面、等待加载
- 🔍 **页面感知** — AI 可获取页面结构化 DOM（按钮/链接/表单/标题），精准定位元素
- 🌐 **网页搜索** — AI 可搜索互联网（DuckDuckGo），获取最新信息
- 📖 **内容提取** — AI 可读取页面全文、后台抓取任意 URL 内容
- ⚡ **执行脚本** — AI 可在页面中执行 JavaScript，获取动态数据
- 📸 **截图分析** — AI 可截取页面，配合视觉模型分析页面内容
- 📑 **标签页管理** — AI 可列出、打开标签页，跨标签页工作
- 🪄 **新标签页自动展开** — Agent 打开的页面自动弹出侧边栏，显示实时进度和工具调用
- 🔄 **跨标签页实时同步** — 所有标签页通过 storage 轮询共享会话，步数和工具调用即时更新
- ✋ **随时打断** — 任何标签页均可停止 Agent 或发送新指令
- 📊 **步数显示** — 状态栏实时显示当前步骤和进度（支持不限制步数）

### 通用 AI 对话
- 🎯 **右侧悬浮球** — 可拖拽定位，点击展开/收起侧边栏
- ↔️ **拖拽调宽** — 左边缘拖拽调整侧边栏宽度（300px ~ 70%），持久化记忆
- 💬 **流式对话** — 支持 SSE 流式响应，逐 token 实时渲染
- 🎨 **MD3 主题** — Material Design 3，6 套配色 × 亮色/暗色/跟随系统
- 📝 **Markdown 渲染** — 标题、列表、代码块（一键复制）、链接、KaTeX 数学公式
- 🕐 **对话历史** — 自动保存 + 历史面板查看/切换/删除，Agent 步骤卡片保留
- ✏ **新建对话** — 一键开启新会话，旧会话自动存入历史
- 🔗 **多供应商管理** — 预设 OpenAI / DeepSeek / 通义千问 / GLM / Moonshot，支持自定义

### 🖼️ 图片理解 & 上下文
- 📎 **附件上传** — `+` 按钮菜单、拖拽文件到侧边栏、Ctrl+V 粘贴图片
- 🌐 **网页上下文** — `+` 菜单 → 添加网页上下文，选择任意标签页提取正文
- 👀 **页面感知** — 打开侧边栏自动提取当前页面内容作为上下文
- ✂️ **框选截图** — 8 个手柄自由调整选区，快速截图松手直接发送
- 👁️ **多模态识别** — 图片直发给多模态模型（如 gpt-4o）
- 📝 **视觉模型转述** — 先调视觉模型描述图片，再交给纯文本主模型

### 🎓 超星学习通自动答题
- 📋 **自动识别** — 检测页面单选题，显示「▶ 自动答题」按钮
- 🤖 **逐题作答** — 提取题目 → 调用 AI → 自动点击选项
- ⏯ **暂停/恢复** — 点击暂停，长按结束
- 📊 **进度显示** — 按钮自身充当进度条
- 📦 **结果面板** — 折叠式答题结果，题号+答案+解析

## 🚀 安装

1. 打开 Edge，访问 `edge://extensions/`
2. 开启右上角 **"开发人员模式"**
3. 点击 **"加载解压缩的扩展"** → 选择项目文件夹

> 修改代码后需在 `edge://extensions/` 点击扩展卡片的 🔄 刷新，**再刷新目标页面**。

## 📖 使用说明

### 首次配置

1. 点击右侧悬浮球 → 展开侧边栏
2. 头部 ⚙️ → 设置页：
   - **供应商**：选择或自定义，填写 Base URL / API Key，管理模型
   - **主模型**：选择模型 + 测试连接 + 系统提示词
   - **视觉模型**：选择模式（无 / 主模型 / 视觉模型转述）
   - **Agent 设置**：启用 Agent 模式 + 配置最大步数（输入 0 不限制）
   - **答题设置**：跳过已答题目 + 快速截图 + 页面感知
   - **主题**：模式（系统/亮/暗）+ 6 种配色

### Agent 模式

**启用：** 设置中开启「Agent 模式」→ 工具栏出现 🤖 按钮并高亮

**使用：**
| 操作 | 方式 |
|------|------|
| 启动 Agent | 在输入框输入任务 → Enter 发送 |
| 查看步骤 | Agent 工具调用卡片自动折叠，点击展开看详情 |
| 查看步数 | 状态栏实时显示「步骤 3/5」或「步骤 5/不限制」 |
| 停止 Agent | 点击 Agent 状态栏右侧 ⏹ 按钮（任意标签页均可） |
| 跨标签页查看 | Agent 打开新页面时侧边栏自动弹出，所有标签页轮询同步 |
| 追加指令 | 在任意标签页侧边栏输入新消息 → Enter |

**Agent 可用工具：**

| 工具 | 功能 | 说明 |
|------|------|------|
| `open_tab` | 打开新标签页 | 新页面自动弹出侧边栏 |
| `click_element` | 点击元素 | 支持选择器/文本/aria-label 定位 |
| `type_text` | 输入文本 | 模拟逐字符输入，可附加 Enter 提交 |
| `get_page_structure` | 获取页面结构 | 返回可交互元素列表含选择器（interactive/headings/links/forms） |
| `get_page_text` | 读取页面全文 | 最多 30000 字 |
| `web_search` | 搜索互联网 | DuckDuckGo，返回标题+URL+摘要 |
| `fetch_webpage` | 后台读取网页 | 无需打开标签页 |
| `list_tabs` | 列出标签页 | 返回 ID/标题/URL |
| `scroll_page` | 滚动页面 | 上下/顶部/底部 |
| `wait_for_element` | 等待元素出现 | 用于页面异步加载等待 |
| `screenshot` | 截取页面 | base64 JPEG |
| `eval_js` | 执行 JavaScript | 可读取页面全局变量（有速率限制） |

**场景示例：** "帮我在掘金搜索 React 19 的最新文章，打开第一篇告诉我主要内容" → Agent 自动完成搜索、点击、阅读、总结全过程。用户可切换到新页面实时观察进度。

### 自动答题（学习通作业页面）

1. 打开作业页 → 展开侧边栏 → 输入框上方出现「▶ 自动答题」
2. 点击 → 开始逐题作答，按钮显示进度
3. 点击 → 暂停（自动保存），再点击 → 恢复
4. 长按 800ms → 结束答题（自动保存）

## 🔒 隐私说明

- API Key 存储于 `chrome.storage.sync`，对话历史存储于 `chrome.storage.local`
- 请求直连服务商，不经过第三方
- 对话历史在浏览器本地持久化，可随时管理/删除
- Agent 工具调用（如 `eval_js`）有速率限制和安全分级
